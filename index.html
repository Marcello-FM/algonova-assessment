Kebijakan Privasi

Algonova berkomitmen menjaga privasi data peserta assessment. Data yang dikumpulkan (nama, usia, sekolah, nomor WhatsApp) hanya digunakan untuk keperluan komunikasi terkait program Algonova dan tidak akan dibagikan kepada pihak ketiga tanpa persetujuan.

Data tersimpan secara aman di database assessment Algonova untuk keperluan evaluasi workshop dan tindak lanjut program belajar anak.
